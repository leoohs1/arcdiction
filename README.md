# Arcdiction

Prediction market gamificado construído na Arc, resolvido pela Pyth.

## Como rodar localmente
1. Instale as dependências: `npm install`
2. Rode o projeto: `npm run dev`
3. Abra http://localhost:3000

## Deploy
Este projeto está pronto para deploy direto na Vercel — basta importar
o repositório na Vercel e clicar em "Deploy". Nenhuma configuração
adicional é necessária para esta primeira versão.
